# /titles

ROOT = `C:\Users\Admin\Documents\YouTube-Playbooks`. Keep chat short.

1. **Read** `ROOT\Tools\data\title_patterns.md`. If a script or production folder is named or obvious (the newest folder in `ROOT\Productions`), read its script or notes too.
2. **Pick the channel.** An NBA moment means MetaSports; anything else means Commentary.
3. **MetaSports.** Write 10 titles, then score each out of 5:
   - +1 for 4–7 words
   - +1 for a question, or a What/How/Why opener
   - +1 for no hashtags, no ALL-CAPS words and no "This…" opener
   - +1 if the viewer needs the ending
   - +1 for one reaction emoji or one strong verb

   Show a table (title · words · score) with the top 3 first. Never promise something the Short doesn't deliver.
4. **Commentary.**
   - Write 10 titles across at least 5 breakout patterns. About 5 words each, like a text to a friend.
   - For the top 3, add a 2–3 word thumbnail text that adds to the title rather than repeating it.
5. **Save** the table into the production folder's `notes.md` or `plan.md` if there is one; otherwise just show it.
